# Elemental Wars - 3D Action RPG

## Overview
Elemental Wars is a premium 3D action RPG featuring elemental combat, challenging boss battles, and a comprehensive Game Pass monetization system.

## Key Features
- **8 Elemental Powers**: Fire, Water, Lightning, Earth, Wind, Ice, Nature, and Light
- **4 Epic Bosses**: Inferno Dragon, Tidal Leviathan, Storm Titan, and Void Sentinel
- **Cross-Platform Support**: PC, Mobile (iOS/Android), and Console (PlayStation/Xbox)
- **Battle Pass System**: Seasonal rewards and progression
- **Cosmetic Shop**: Skins, effects, and animations
- **Subscription Tiers**: Free, Premium, and Premium Plus

## System Requirements
- **Unity**: 2022.3 LTS or newer
- **Platform**: Windows, Mac, Linux, iOS, Android, PlayStation 5, Xbox Series X/S

## Quick Start
1. Open the project in Unity 2022.3+
2. Read `SETUP_GUIDE.md` for configuration
3. Load the `MainScene` from Assets/Scenes
4. Press Play to test the game
